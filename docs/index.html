Fra tom maskin til ferdig mediaserver.

Én veiviser setter opp Jellyfin og alt rundt den på Docker, og kobler appene sammen for deg. Gratis og åpen kildekode hele veien. Plex kan velges i stedet.

Last ned Andre systemer

Linux, macOS og Windows. Gratis og åpen kildekode.

Tre steg, ingen innstillingssider

Du svarer på noen spørsmål. Resten gjør oppsettet selv: mapper, innlogging, nedlastere, VPN, kvalitetsprofiler og koblingen til mediaserveren.

  1. Pakk ut og start

    Last ned pakken for systemet ditt og start start.sh, Start.command eller Start.bat.

  2. Svar på spørsmålene

    Jellyfin eller Plex, hvor filmene ligger, et passord og en VPN-nøkkel. Det tar et par minutter.

  3. Alt kobles sammen

    Appene settes opp via API-ene sine, og du får en oppsummering. Du kan kjøre oppsettet igjen så ofte du vil.

Last ned

Velg pakken for maskinen som skal være server. Docker må være installert. På Linux tilbyr startskriptet å installere det for deg.

Ditt system

Linux

Anbefalt. Jellyfin får maskinvare-transkoding gratis. Passer fint på en gammel bærbar eller en hjemmeserver.

./start.sh Last ned for Linux
Ditt system

macOS

macOS 14 eller nyere, med OrbStack eller Docker Desktop. Transkoding skjer med prosessoren.

Dobbeltklikk Start.command Last ned for macOS
Ditt system

Windows

Windows 10 eller 11, med Docker Desktop og WSL 2. Transkoding skjer med prosessoren.

Dobbeltklikk Start.bat Last ned for Windows

Eldre versjoner og endringslogg ligger under Releases. Kildekoden ligger på GitHub.

Det du gjør selv

  • Legg inn indeksere i Prowlarr. De deles automatisk med Sonarr og Radarr.
  • Velg undertekstkilder i Bazarr.
  • Lag brukere til familien i Jellyfin, eller inviter dem med Wizarr.
  • Har du Usenet, trenger du også en NZB-indekser.

Ansvar

Film-stack setter opp programvare. Med Jellyfin er alt åpen kildekode. Du er selv ansvarlig for hva du laster ned, og for å følge lovene der du bor. All torrent-trafikk går gjennom VPN-en.
