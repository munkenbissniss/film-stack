Three steps, no settings pages

You answer a few questions. The setup does the rest: folders, logins, downloaders, VPN, quality profiles and the connection to the media server.

  1. Unzip and start

    Download the package for your system and run start.sh, Start.command or Start.bat.

  2. Answer the questions

    Jellyfin or Plex, where your movies are, a password and a VPN key. It takes a couple of minutes.

  3. Everything gets connected

    The apps are set up through their APIs, and you get a summary. You can run the setup again as often as you like.

Download

Pick the package for the machine that will be the server. Docker must be installed. On Linux, the start script offers to install it for you.

Your system

Linux

Recommended. Jellyfin gets hardware transcoding for free. Works well on an old laptop or a home server.

./start.sh Download for Linux
Your system

macOS

macOS 14 or newer, with OrbStack or Docker Desktop. Transcoding runs on the CPU.

Double-click Start.command Download for macOS
Your system

Windows

Windows 10 or 11, with Docker Desktop and WSL 2. Transcoding runs on the CPU.

Double-click Start.bat Download for Windows

Older versions and the changelog are under Releases. The source code is on GitHub.

What you do yourself

  • Add indexers in Prowlarr. They are shared with Sonarr and Radarr automatically.
  • Pick subtitle providers in Bazarr.
  • Create users for the family in Jellyfin, or invite them with Wizarr.
  • If you use Usenet, you also need an NZB indexer.
